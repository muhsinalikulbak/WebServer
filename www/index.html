Epoll Event Loop

Sunucu Konfigürasyon Yapısı

Nginx benzeri esnek ve okunabilir blok yapısı

webserver.conf NGINX-style Syntax 
server {
    listen 127.0.0.1:8080;
    server_name example.com;
    client_max_body_size 10M;

    error_page 404 /errors/404.html;
    error_page 500 /errors/500.html;

    location / {
        allow_methods GET POST;
        root ./www;
        index index.html;
        autoindex on;
    }

    location /cgi-bin {
        allow_methods GET POST;
        root ./www/cgi-bin;
        cgi_ext .py /usr/bin/python3;
    }
}
